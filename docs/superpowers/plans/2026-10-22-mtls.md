# mTLS service traffic implementation

**Goal:** Authenticate Atrium to app-engine MCP and app-engine to configured app-store or Atrium HTTPS origins with client certificates, while retaining bearer authorization for MCP.

**Architecture:** A dedicated nginx listener checks Atrium's client certificate, forwards only `/api/mcp`, and sends a high-entropy internal assertion over loopback. App-engine accepts that assertion only from loopback and still checks its independent bearer key. StoreBridge selects an SSL context containing app-engine's client certificate only when the requested origin exactly matches an operator-configured HTTPS origin. Atrium MCP and app-store server changes are developed in their own repository worktrees.
